📘 Guia Técnico: Operações de Gestão

1. Salvando Alterações (Edição)

O processo de edição é uma "atualização segura". O sistema identifica o registro através do parâmetro id na URL. A interface preenche o formulário automaticamente via prepararEdicao().

  • Tratamento de Imagem: Se um novo arquivo for enviado, o sistema gera um nome único e substitui o antigo no Storage. Caso contrário, mantém o link existente.
  • Método HTTP PUT: Diferente do cadastro, a edição utiliza PUT, informando ao servidor Node.js que deve atualizar um registro em vez de criar um novo.

2. Excluindo Produtos

A exclusão exige confirmação para evitar perdas acidentais.

  • Gatilho: O botão "Excluir" dispara um evento confirm().
  • Limpeza Física: Antes de apagar do banco, o sistema remove a foto correspondente do Supabase Storage.
  • Método HTTP DELETE: A requisição é enviada para o endpoint específico do produto.

3. O Papel Central do Backend (A Ponte)

A comunicação depende da validação de segurança via headers:

  • Headers: Injeção obrigatória de x-api-key e Content-Type: application/json.
  • Modularidade: Este modelo garante que, se o banco de dados mudar no futuro, apenas o arquivo db.js precisará de ajustes, mantendo o comportamento do Painel e do PHP padronizados.
